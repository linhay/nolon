## 2. 负反馈记录
1. “CLI 重新登录应该在右键菜单里”
   - 触发上下文：账号卡片顶部按钮布局讨论后。
   - 根因：交互入口放置与用户既定操作习惯不一致。
   - 影响范围：账号卡片交互一致性与误触风险。
2. “进入 tab 会不停刷新账号 / 避免触发刷新”
   - 触发上下文：监听 `~/.nolon/codex/auth` 目录时大量 `renamed` 事件触发。
   - 根因：未充分区分临时文件（`.dat.nosync*`）和真实 auth 变更事件，抑制窗口与去抖策略不够细。
   - 影响范围：性能、日志噪音、误刷新。
3. “点击 cli 登录后关闭浏览器不能重新点击登录了”
   - 触发上下文：CLI 登录中止/取消后再次登录。
   - 根因：登录任务状态与 UI 可点击态未完全解耦，取消路径状态清理不完整。
   - 影响范围：CLI 登录可恢复性。
4. “CLI 登录 未能完成操作（Swift.CancellationError错误1）”
   - 触发上下文：切账号或重复点击导致任务取消。
   - 根因：把用户主动取消与异常失败统一作为 alert 错误路径处理。
   - 影响范围：错误提示准确性与用户信任。
5. “卡片背景和文字颜色在深色模式下看不清”
   - 触发上下文：账号卡片及后续 skill/workflow/mcp 卡片。
   - 根因：默认卡片背景与边框对比不足，且样式分散在多个组件未统一治理。
   - 影响范围：深色模式可读性与视觉一致性。

### 6.3 负反馈记录（逐条）
1. “上方的 tip 允许关闭, 软链接开关没显示”
   - 根因：状态/条件渲染覆盖不完整，缺少关闭交互。
   - 影响：功能可发现性。
2. “这个布局也太难看了 / 这样真的难以理解”
   - 根因：信息密度高，区块层级和视觉对比不合理。
   - 影响：可读性与认知负担。
3. “codex 和 codex(xcode) 切换时 advanced 内容没变”
   - 根因：`@State` viewModel 初始化后未同步 provider 变化。
   - 影响：切换场景显示错误，误导配置操作。
4. “推理强度不是应该显示在 run preferences 区吗?”
   - 根因：信息分组与用户心智模型不一致。
   - 影响：配置路径不直观。
5. “激活和已激活, 按钮字号, 大小被改变了”
   - 根因：同语义控件使用不同样式组件（按钮 vs 文本胶囊）。
   - 影响：视觉跳动、专业感下降。
6. “在 finder 中显示可以移动到右下角 ... 按钮和右键菜单中”
   - 根因：次要动作入口过于显性且占位。
   - 影响：主操作（链接开关）视觉焦点被分散。
