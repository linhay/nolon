## 2. 负反馈记录
1. “读取到的数据不对 / 数量不对”
   - 触发上下文：模型列表读取与展示。
   - 根因：读取源与解析逻辑不匹配真实 CLI 交互输出，导致模型数量与内容不一致。
   - 影响范围：Run Preferences 的模型列表准确性。
2. “卡片不要一短一长 / 遵守 DesignSystem”
   - 触发上下文：Run Preferences 与 Update/Download 卡片布局。
   - 根因：布局未按 DesignSystem 的卡片高度/自适应规则处理。
   - 影响范围：UI 一致性、视觉规范。
3. “More 按钮内功能可以展开，宽度不够再出现 More”
   - 触发上下文：Update/Download 卡片按钮布局。
   - 根因：固定展示 More 而未按可用宽度动态折叠。
   - 影响范围：操作可见性与信息架构。
4. “Open Config 路径错了（打开的是 Xcode Codex 配置）”
   - 触发上下文：配置按钮。
   - 根因：路径分支未区分统一版本目录与 Xcode 配置。
   - 影响范围：配置操作错误。
5. “不能实现交互的终端再获取吗？”
   - 触发上下文：终端 app 检测。
   - 根因：未区分交互式终端能力与仅打开文件/路径的应用。
   - 影响范围：Open CLI 体验。
