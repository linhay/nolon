## 2. 负反馈记录
1. **“resetDescription / resetsAt 显示规则不符合预期”**
   - 触发上下文：ProviderUsageView 的 Codex 配额展示。
   - 根因：先按常规文案展示，再被要求按 “周期 + 倒计时 + resetsAt”/“resets in 5d23h” 精确格式。
   - 影响：多次返工 UI 逻辑与文案格式。

2. **“布局要求：period 左 / countdown 右”**
   - 触发上下文：Codex 配额行。
   - 根因：初版采用单行拼接文本而非左右分栏。
   - 影响：需要改为 `HStack + Spacer` 布局。

3. **“单位要求：英文 w/d/h/m，中文 周/天/小时/分钟”**
   - 触发上下文：周期与倒计时单位显示。
   - 根因：采用默认 DateComponentsFormatter（缩写不符合要求）。
   - 影响：需要自定义单位映射并按语言切换。

4. **“编译错误：私有类型泄漏导致方法访问级别报错”**
   - 触发上下文：CodexAuthService 新增私有结构体后 helper 未标 `private`。
   - 根因：私有类型用于非私有方法签名。
   - 影响：阻断编译，需要补齐访问级别。

5. **“发布脚本失败：Tag already exists”**
   - 触发上下文：`./scripts/release.sh` 重跑时。
   - 根因：tag 已存在导致脚本退出。
   - 影响：中途改为手动提交 appcast、推送、创建 release。
