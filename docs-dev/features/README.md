# Feature Specs

本目录用于需求与功能规格文档。

建议结构：
- `feature-name/spec.md`：目标、范围、验收标准（BDD 场景）
- `feature-name/changes.md`：增量变更记录

当前可用文档：
- `docs-dev/features/codex-full-support-spec.md`：Codex 全面支持目标、范围、约束与 BDD 验收标准。
- `docs-dev/features/codex-usage-card-status-spec.md`：Codex 账号卡片状态展示与错误操作布局规格。
- `docs-dev/codex/codex-clikit/`：历史 Codex 方案与实现细节归档。
