3 步上手

从下载到日常使用，只保留必要动作。

  1. 安装并打开 Nolon

    从 Release 下载最新版本，首次启动后进入主控制台。

  2. 连接你的 Provider

    按已支持模板接入 Skills / Workflows / MCP 资源。

  3. 在一个入口完成编排

    在主控制台统一查看、安装、切换与诊断，减少重复操作。

主控制台：稳定的日常操作路径

左侧选择 Provider，中间切换任务视图，右侧查看细节状态，路径固定更易维护。

资源中心：发现、安装、同步

把分散资源集中到一条安装路径，减少跨工具手工配置。

Skills

统一管理技能资产并投射到目标 Provider。

Workflows

安装工作流并保持本地与远程一致。

MCP

安装与配置 MCP 资源，减少手工配置错误。
