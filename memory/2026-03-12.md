## Clawhub 远程列表 429 限流重试（2026-03-12）
- 现象：资源中心远程 skill 列表在 `https://clawhub.ai` 返回 HTTP 429 时直接失败，日志为 `Remote list failed with status 429`。
- 根因：`SkillsRepositoryFacade.performListRemoteResourcesRequest` 缺少与下载链路一致的同 host 限流重试；下载已有最多 3 次尝试，列表没有。
- 修复：
  - 为远程列表请求补齐 429 重试逻辑，沿用 `Retry-After` 解析与 1...30 秒裁剪。
  - 最大尝试次数统一为 3 次（首次请求 + 2 次重试）。
  - 不引入镜像域名回退，保持当前 `clawhub.ai` 单域行为。
- 测试：
  - 新增 `list remote resources retries once on same host after 429`
  - 新增 `list remote resources returns 429 after same-host retry exhaustion`
  - `swift test --package-path libs/Providers --filter SkillsRepositoryFacadeTests` 通过。

## Gemini 用量页激活账号重复展示修复（2026-03-12）
- 现象：Gemini 用量 tab 在账号卡下方又显示一张同一激活账号的 outcome 卡，看起来像出现两个相同账号。
