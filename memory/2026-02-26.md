## 20:30 App 安装链路修复：RemoteCatalog localPath 丢失
- 现象：CLI 修复后可安装 `sectionkit`，但 App 仍失败。
- 根因：App 的查询链路 `RemoteCatalogQueryService -> RemoteCatalogItemMapper -> RemoteSkill` 中，`RemoteCatalogItem` 未携带 `localPath`，导致本地/Git 资源在 UI 安装时被当成远端下载处理。
- 修复：
  - `SkillsRepositoryFacade.RemoteCatalogItem` 新增 `localPath` 字段（默认 nil）。
  - `RemoteCatalogItemMapper` 双向映射补齐 `localPath`（skill/workflow/mcp）。
  - `RemoteCatalogQueryService` 直接映射原始 remote model，避免重建时丢失 `localPath`。
- 验证：
  - `swift test --package-path libs/Providers --filter remoteCatalogQueryServiceQueriesLocalFolder` 通过。
  - `swift test --package-path libs/Providers --filter remoteCatalogItemMapperConvertsItems` 通过。
  - `xcodebuild -project nolon.xcodeproj -scheme nolon -configuration Debug -sdk macosx build` 通过。
