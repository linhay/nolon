## 02: GitHub 安装 skill 链路安全加固
- 修复 `remote sync-install --path` 仓库边界问题：解析后若路径不在 synced repository root 内，直接 `invalid_arguments`。
- 修复 install 输入路径片段风险：`skill-id` / `resource-name` 必须是单段名称，禁止 `../`、`/`、`.`、`..`。
