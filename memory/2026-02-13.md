## Codex EventMsg 全量兼容（libs/codex 对齐）
- 决策：按 `libs/codex` schema 扩展 `event_msg` 兼容类型，不采用严格报错。
- 策略：
  - 核心事件维持强类型（token_count/user_message/agent_message/error/warning/task_*）。
  - schema 内其他事件统一映射 `.known(type:payload:)`。
  - schema 外未知事件保持 `.other(type:payload:)`。
- 新增测试：`CodexEventMsgCompatibilityTests`
  - `EventMsg` 全量列表映射测试（token_count 特判为顶层 `.tokenCount`）
  - `ResponseItem` 全量类型映射测试
- 结论：usage 与 CLI 回归均通过，兼容扩展未引入行为回归。
