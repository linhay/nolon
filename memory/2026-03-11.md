# 2026-03-11

## Codex
- Codex auth 导入增强：支持批量数组 JSON（`[ {...}, {...} ]`）文件导入；导入时把顶层 token 字段规范化写入 `tokens.*`，并将 `expired` 映射为 `expires_at`（当缺失时）。
- Email 推断扩展：导入/展示时 `email` 候选包含 `user.email`（优先级：`email -> user.email -> nolon.account.email`）。
- 安全校验：若导入 JSON 含 `type` 且不为 `codex`（忽略大小写），候选项直接判无效。

## Claude
- Claude 账号配置第一阶段完成：模板开启账号能力（`supportsAccounts/supportsMultiAccount`），`claudeCode` 已可映射到 `UsageProvider.claude`（Usage 页与账号页可识别）。
- ProviderUsage 新增 `ClaudeUsageDescriptor`：复用 `CodexHTTPUsageQueryExecutor` 支持可配置 HTTP 用量查询，Claude 不再走 registry unsupported。
- `ClaudeAccountManager` 关键能力落地：
  1. 从当前 Claude `settings.json` 手动迁移导入
  2. 从 `cc-switch` SQLite 导入 Claude 账号
  3. 冲突时按“有效账号优先（在线探测）”替换
  4. 激活账号写回 `settings.json`
- 修复递归缺陷：`ensureStorage()` 与 `saveAccounts()/setActiveAccountID()` 互调导致栈溢出（SIGBUS），已拆分底层写入函数并补测试防回归。
- Claude 账号导入修复：`importFromCCSwitch` 新增 cc-switch 配置兼容层，支持从 `settings_config` 的 `env`、`*.env`、顶层 `apiKey/api_key` + `base_url/baseURL/apiEndpoint` 解析；并支持从 `~/Library/Application Support/com.ccswitch.desktop/app_paths.json` 读取 `app_config_dir_override` 以定位自定义 `cc-switch.db`。
- 增加回归测试 `importFromCCSwitchSupportsTopLevelKeys`，验证非 `env` 结构也能成功导入。
- Claude/Codex/Accounts 卡片样式收敛：新增通用 `AccountSummaryCard` 与 `AccountCardPresentation`，统一 Accounts 页摘要卡、Usage 页 Codex 卡、Usage 页 Claude 卡和 loading skeleton 的外层表面/选中态；`PiAccountSummaryCard` 已移除，PI 只读信息并回主卡片内容区。
- 验证结果：`./build.sh` 构建通过；`xcodebuild test -project nolon.xcodeproj -scheme nolon-tests -only-testing:nolonTests/AccountCardPresentationTests` 通过 4/4。

- Codex 导入账号修复：`导入账号` sheet 内的“选择文件”改为直接使用 `NSOpenPanel`，避免父层 `fileImporter` 在 macOS sheet 场景下不弹出 Finder；并补了“选择成功/取消”两条 BDD 测试。

- Codex Advanced 配置修复：
  - 根因：`Advanced` tab 的结构化控件在初始化灌值时可能触发自动保存，且保存链路用 `CodexConfigToml + TOMLEncoder` 整文件重写，导致现有 `config.toml` 中未建模字段、注释与额外 section 被裁剪。
  - 决策：改为文本级结构化草稿提取 + 增量 patch 保存，只修改受控键；新增 hydration guard，阻止首次加载阶段的自动保存。
  - 风险边界：受控 block 内部的原始键顺序与局部注释不保证完全保留，但 block 外的未知 TOML 内容会保留。
  - 验证：`xcodebuild -project nolon.xcodeproj -scheme nolon-app -destination 'platform=macOS' test -only-testing:nolonTests/CodexAdvancedConfigRoleDraftTests` 通过。
