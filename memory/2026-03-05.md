## Gemini 已登录但 App 仍提示无 active account（2026-03-05）
- 问题：用户终端已登录 Gemini CLI，但 Usage 卡片仍显示 `No active account for gemini. Please sign in.`。
- 根因：App 只读 `GeminiAuthStore`（Nolon 私有账号仓），不会自动吸收 `~/.gemini` 的历史登录缓存。
- 实现：
  - 按新要求改为“用户确认后导入”，不做自动导入。
  - `GeminiAuthStore` 新增：
    - `globalSessionImportCandidate(provider:environment:)`：仅检测可导入会话。
    - `importFromCLIGlobalSession(provider:environment:)`：仅在确认后执行导入。
  - `GeminiUsageDescriptor.fetchOutcome` 保持纯读取（无 active account 仍返回 `missingAccount`）。
  - `ProviderUsageViewModel/ProviderUsageView`：
    - Gemini 点击 `登录` 时先检测候选会话并弹确认框。
    - 用户点 `Import` 才导入；点 `Continue OAuth Login` 则继续 Gemini OAuth 登录流程。
- 测试：
  - `GeminiAuthStoreTests` 新增/更新 3 条：
    - `detects import candidate from existing Gemini CLI login cache`
    - `imports only after explicit confirmation call`
    - `import candidate keeps antigravity isolated from global gemini cache`
  - `swift test --package-path libs/Providers --filter GeminiAuthStoreTests --filter GeminiUsageDescriptorTests --filter GeminiLoginRunnerTests` 通过（12 tests）。
  - `xcodebuild ... -only-testing:nolonTests/CodexUsageTabPresentationTests -only-testing:nolonTests/UsageIssueClassifierTests` 通过。
