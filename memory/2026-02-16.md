- JsonRPCKit 迁移阻塞结论：
  - `SKProcessRunner` 当前无“非 PTY 双向长连接会话”API，仅有一次性 `run*` 与 `SKProcessPTYSession`。
  - JSON-RPC over stdio 对 pipe 语义有要求，直接改用 PTY 有协议污染风险。
  - 新增 issue 草案文档：`docs-dev/dev/skprocessrunner-jsonrpc-session-issue.md`（含建议 API `SKProcessPipeSession` 与验收标准）。
  - 当前 `libs/Providers/Sources` 中 `Process` 唯一例外为 `JsonRPCKit/JsonRPCLineProcessSession.swift`。
