## Codex Gateway HOME / NOLON_HOME 路径语义修正
- 继续做 gateway 真机 smoke 时发现一个真实问题：
  - `gateway config.toml` 解析想走测试注入的 `HOME`
  - 但 `.nolon` 状态目录实际走的是 `NOLON_HOME`
- 修正后：
  - `NolonLiveCodexCLIService.defaultGatewayConfigFile` 会把 `Provider.defaultSkillsPath` 中基于 `NSHomeDirectory()` 展开的前缀替换成运行时 `HOME`
  - `gateway start/stop` 的配置 patch 现在可正确落到覆盖后的 `~/.codex/config.toml`
- 验证结果：
  - `swift test --package-path /Users/linhey/Desktop/FlowUp-Libs/nolon/libs/Providers --filter gatewayStartResolvesConfigPathFromHomeOverride` 通过
  - 直接运行已构建 `nolon` 二进制，在同时设置 `HOME` 与 `NOLON_HOME` 的临时目录下完成：
    - `gateway start`
    - `GET /healthz -> 200`
    - `POST /v1/responses -> 503`（空账号池）
    - `gateway.pid` / `state.json` 正常生成
    - `gateway stop`
    - `config.toml` 被正确恢复/移除
