## 12:44 修复 app-server bool 参数被编码为整数（1/0）
- 现象：报错 `-32600 Invalid request: invalid type: integer 1, expected a boolean`。
- 根因：`JsonRPCLineProcessSession.anyCodable(from:)` 中 `NSNumber` 分支在 `Bool` 之前，导致 `true/false` 先被桥接为 `NSNumber(1/0)` 并按整数编码。
- 修复：将 `Bool` 分支前移到 `NSNumber` 之前，确保 JSON 参数类型保持布尔。
- TDD：新增 `JsonRPCKitTests.encodeParamsPreservesBoolType`，断言输出为 `"experimentalApi":true` 且不为 `1`。
- 验证：
  - `swift test --package-path libs/Providers --filter "JsonRPCKitTests/encodeParamsPreservesBoolType|JsonRPCKitTests/requestRoundTripAndNotification|CodexAppServerKitTests/mapsInvalidParamsCategory"` 通过。
