## 修复 Codex 用量“假正常”
- 问题确认：`nolon codex auth usage --refresh` 在刷新失败时会保留旧 `usage_cache`，导致界面仍显示历史配额，看起来“正常”。
- 根因：刷新失败只写 `lastSyncFailedAt/lastSyncFailureMessage`，未失效缓存；汇总统计继续计入旧缓存账号。
- 修复：
  - `NolonLiveCodexCLIService.refreshUsageCaches` 失败分支改为 `clearUsageCache` + 记录失败元数据。
  - `buildAuthUsagePayload` 在本次刷新失败账号上强制不读缓存，并输出账号级失败时间/原因。
  - CLI 文本新增 `[刷新失败]` 分区，summary 增加“刷新失败账号”统计。
- 验证：
  - `swift test --package-path libs/Providers --scratch-path /tmp/providers-spm-refresh-stale --filter NolonCodexCLIServiceTests`
  - `swift test --package-path libs/Providers --scratch-path /tmp/providers-spm-refresh-entry --filter authUsageRendersRefreshFailureSection`
