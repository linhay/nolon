# Claude 用量页空状态卡片样式统一（2026-03-13）

## 背景
- `Claude Code / 用量` 页面在没有 Claude 账号时，会显示一个裸 `ContentUnavailableView`。
- 该空状态没有沿用 Provider 页内其他卡片的背景、边框与居中布局，看起来像内容直接贴在页面上，层级感不足。

## 目标
- 将 Claude 用量页的空状态统一为卡片化展示。
- 空状态内容在卡片内保持水平居中，并具备明确的背景色、边框和内边距。

## BDD 验收场景
1. Given Claude 用量页没有任何账号，When 打开页面，Then 空状态以卡片形式展示，并带有背景色、边框和内边距。
2. Given Claude 用量页没有任何账号，When 打开页面，Then 标题、图标和说明文案在卡片区域内水平居中。
3. Given Claude 用量页已经有账号，When 打开页面，Then 仍展示原有 Claude 账号卡片网格，不受本次空状态样式调整影响。

## 非目标
1. 本次不调整 Claude 账号卡片本身的信息结构或交互。
2. 本次不修改 `cc-switch` 导入逻辑和空状态文案内容。
