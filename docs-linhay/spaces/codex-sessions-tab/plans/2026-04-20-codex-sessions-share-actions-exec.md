# Codex Sessions 分享动作执行计划（2026-04-20）

## BDD 场景

### 场景 1：单会话详情支持直接分享
- Given 用户已展开某个会话详情卡片
- When 点击详情动作区的 `Share`
- Then 系统分享面板收到该会话的结构化摘要文本

### 场景 2：整组分享覆盖折叠组的隐藏会话
- Given 某个项目组已折叠，界面仅显示前 5 条会话
- When 从组头菜单触发 `Share Group`
- Then 分享内容仍包含该组全部会话，而不是只包含当前可见行

## 执行步骤
1. 先补失败测试：
   - 单会话分享文本包含核心字段。
   - 整组分享文本覆盖折叠组隐藏会话。
2. 实现分享文本构建器。
3. 给详情卡片增加 `Share` 按钮。
4. 给组头菜单增加 `Share Group` 菜单项。
5. 跑相关测试与构建验证。
6. 更新 `docs-linhay/memory/2026-04-20.md`，执行 `qmd update && qmd embed`。

## 风险
- SwiftUI `Menu` 中的分享能力需要使用系统支持的分享入口，不能退化成“复制文本”假分享。
- 组分享必须以 ViewModel 内部的全量 section state 为准，不能直接复用当前可见 section 的 5 条可见行。
