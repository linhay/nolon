# Codex Sessions 分享动作（2026-04-20）

## 背景
- 当前 `Codex Sessions` 只支持 `Resume`、`Copy Command`、`Show in Finder` 和组级 `Move`。
- 用户需要两类分享能力：
  - 单个会话可直接分享。
  - 单个会话组可从组头菜单整体分享。

## 目标
1. 单会话详情卡片增加明确的分享按钮。
2. 组头保留菜单式操作入口，并新增整组分享菜单项。
3. 分享内容不是裸路径，而是结构化摘要，包含当前浏览上下文中的关键信息。

## 验收标准
1. 展开单个会话详情后，可直接触发系统分享面板。
2. 每个会话组都存在一个可发现的菜单入口，菜单内包含 `Share Group`。
3. 单会话分享内容至少包含：标题、线程 ID、Provider、时间信息、用量、项目路径或组名、rollout 路径。
4. 整组分享内容至少包含：组标题、分组范围、会话数量、用量摘要，以及该组全部会话列表。
5. 当组处于折叠状态时，整组分享仍以全量会话为准，而不是只分享当前可见的前 3 条。

## 非目标
- 本轮不新增“批量选择若干会话后分享”的能力。
- 本轮不改动会话排序、搜索和缓存链路。
- 本轮不新增自定义导出文件格式，优先分享纯文本摘要。
