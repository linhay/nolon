# Codex 账号卡片状态展示规格

## 目标
- 简化 Codex 账号卡片状态表达，减少重复文案。
- 在认证失败场景强化操作可达性（复制错误、重新登录）。

## 范围
- 包含：`Usage` 页面中 Codex 账号卡片的状态点、错误摘要与操作按钮布局。
- 不包含：SDK/CLI 协议、刷新策略、认证链路改造。

## 交互规则
1. 正常/失败状态不再显示横幅条，仅在账号名前显示状态点。
2. 状态点颜色规则：
   - 健康：绿点
   - 失败/需重登录：红点
   - 待刷新：灰点
3. 错误态不显示 Session/Weekly 进度条。
4. 错误操作按钮布局：
   - 仅有“复制错误”时，按钮全宽。
   - 同时存在“复制错误”和“重新登录”时，两按钮平分卡片宽度。

## BDD 验收
1. Given 账号健康，When 打开卡片，Then 标题前显示绿点，且无状态横幅。
2. Given 账号认证失效，When 打开卡片，Then 标题前显示红点，显示错误摘要，不显示进度条。
3. Given 认证失效且支持重登录，When 展示按钮，Then “复制错误”和“重新登录”等宽平分。
4. Given 非认证失败，When 展示按钮，Then 仅“复制错误”且按钮全宽。
