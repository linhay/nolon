## Codex 启动预检托管边界收紧
- 用户边界：如果 `~/.codex/auth.json` 在启动时已经不是 Nolon 托管的软链接，或软链接目标不再指向 `~/.nolon/codex/active-auth/`，则视为外部修改，不再按当前选中账号强行回写 `auth.json` / `config.toml`。
- 实现调整：`preflightManagedAuthIfNeeded(... reason: "usage_load" | "background_poll")` 新增托管所有权检查；一旦失去托管所有权，立即清空 active selection、恢复托管 config、保留现有 provider auth 文件并暂停后续自动接管。
- 行为变更：后台轮询不再因为外部 `auth.json` 后续变成“稳定身份”而自动重新认领；只有显式重新激活账号才恢复托管。
- 回归覆盖：新增启动期 detached regular file / external symlink 两个场景测试，并把“暂停后自动恢复接管”的旧测试预期改为“不自动接管”。
