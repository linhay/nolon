## CLI DX Phase2.2：`auth login` Ctrl+C 残留进程修复
- 现象：`nolon codex auth login` 执行中按 `Ctrl+C`，偶发残留 `codex login` 进程（node + vendor codex 子进程）。

- 实测：`nolon codex auth login` 后 `Ctrl+C`，进程退出码为 `130`，`runtime list` 无 `codex login` 残留。
