## Micro-Sync 01
- 修复 Copilot usage 在 app UI 仍显示 `Missing token for copilot.` 的问题。
- 根因：
  - Copilot 官方 CLI 当前登录态来自 `gh auth token`

  - 普通 PATH 查找改为 fallback
  - `PATH` 处理改为补强常见路径，而不是仅在空值时覆盖
  - 进一步对齐 Codex 的环境加载口径：执行 `gh auth token` 前先合并用户 shell 环境，再应用显式环境覆盖
  - Copilot usage 拉取时补充 GitHub `/user` viewer profile，用于展示 login / name，避免 UI 落到 `Unknown Account`
  - Copilot plan 展示改为 humanize，例如 `individual -> Individual`
  - 修复 viewer profile 一直拿不到的问题：`CopilotUsageFetcher` 原先对 `/user` 也带了无效的 `X-Github-Api-Version: 2025-04-01`，GitHub REST 实际返回 400；已改为稳定版本 `2022-11-28`
- 测试：

  - 更新 `NolonCoreCLIKitTests+Copilot`

## Micro-Sync 03
- 对 `Codex Sessions` tab 上方 `overview card` 发起一轮 `$debate`，范围只限定在 overview card，不扩展到 section rows。
- 关键代码事实：
  - `overview card` 当前固定为 `header -> segmented picker -> statusBanners -> metrics` 四层纵向堆叠
  - 外层常量偏大：`spacing: 18`、`.padding(22)`、refresh `.controlSize(.large)`、metric `minHeight: 82`
  - subtitle 为长说明句，当前完整展开
  - status 区允许 `statusMessage` 与 `backgroundScanningMessage` 双 banner 叠加
- 有效结论：
  - 不建议只做纯常量压缩
  - 最小正确方案应为：
    1. 把 `segmented picker` 并入 header 控制区
    2. 同时收紧 `spacing/padding/controlSize/metric minHeight`
    3. 如窄宽仍偏高，再把 subtitle 限制为最多 2 行
    4. 若状态区仍压首屏，再考虑把双 banner 合并为更轻的单条状态展示
- 辩论文档：
  - `docs-linhay/debate/20260416/codex-sessions-overview-card/20260416-codex-sessions-overview-card-v01.md`
- 工具阻塞：
  - Claude Code CLI 本轮未能参与有效发言，`claude -p` / `claude --model sonnet -p` / `claude --bare --model sonnet -p` 均被本机错误模型配置 `gpt-5(medium)` 阻塞
