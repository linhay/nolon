## 通用单选/多选器落地（主工程视图复用）

- 决策：新增范型选择器 `GenericSelectionControl<Value, Content>`，同一组件支持三种绑定形态：
  - `Binding<Value>`（单选，非空）
  - `Binding<Value?>`（单选，可清空）
  - `Binding<Set<Value>>`（多选）
- 设计：将状态切换逻辑下沉到 `GenericSelectionStateResolver`，视图只负责渲染与交互包装。
- 接入范围：
  - `OnboardingProviderSelectionView`（多选 provider）
  - `NolonAccountsView`（单选时间窗）
  - `AppSettingsView`（单选分类）
  - `AddRepositorySheet`（单选仓库模板）
- 范式对齐：新增 `GenericSelectionControlViewModel` 并补齐 `ViewComponentBindable` 绑定。
- 测试：新增 `GenericSelectionControlTests`（5 个用例）验证单选/多选状态机行为；`ViewComponentParadigmTests` 与 `nolon-tests` 全量通过。
