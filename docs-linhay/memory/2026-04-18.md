## Micro-Sync 01:28
- 修复 `Codex Sessions` 在 `按用量` 排序下“组和组之间看起来没有排序”的口径错位问题。
- 根因不是 section 排序函数失效，而是“组头展示口径”和“组排序口径”不一致：
  - `CodexSessionsTabViewModel.sortSections(...)` 一直按整组聚合总 token 排序。
  - `CodexSessionsSectionDataBuilder` 之前只聚合 `section.sessions`，而折叠态下这里通常只包含当前可见的前 5 条 row。
  - 结果是 UI 组头显示的 usage 只代表“可见子集”，用户看到的数字与实际排序依据不一致，因此误判为组间未按 usage 排序。
- 本轮修复：
  - `SessionSection` 新增 `usageSessionIDs`
  - 组头 usage 改为按整组全部 session 聚合，不再依赖折叠态可见 rows
  - 保持“组头聚合来源”和“列表当前可见 rows”两条数据链路分离
- 验证结果：
  - 新增 `testBDD_GivenCollapsedSectionWithHiddenSessionUsage_WhenBuildingSectionData_ThenGroupUsageIncludesHiddenSessions`

  - `xcodebuild test -skipPackageUpdates -project nolon.xcodeproj -scheme nolon-tests -destination 'platform=macOS' -only-testing:nolonTests/CodexSessionsTabViewModelTests` 通过
  - `xcodebuild test -skipPackageUpdates -project nolon.xcodeproj -scheme nolon-tests -destination 'platform=macOS' -only-testing:nolonTests/CodexSessionsOverviewDataBuilderTests -only-testing:nolonTests/CodexSessionsCardSnapshotTests` 通过
