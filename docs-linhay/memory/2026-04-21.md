## Codex Usage 手动刷新改为缓存增量回填

- 背景：`Intraday Drilldown` 之前经常表现为“加载不出来”，根因不是视图没渲染，而是 `selectedTokenTrendDayKey == nil` 时下方 drilldown 分支根本不会出现；同时旧的 intraday 请求晚返回时还可能覆盖当前选择。
- 本次收敛：

  - 新增 intraday request id guard，只接受“当前最新请求 + 当前选中 day + 当前 bucket”匹配的结果，避免旧请求脏回写。
  - intraday 面板刷新改成同时拉取 token trend + intraday，避免用户刷新下方面板时仍看到过期的日级汇总。
  - 若用户手动收起 drilldown，后续 token trend refresh 不会自动重新展开。
