- 问题修复：`SkillDetailView` 右上角关闭按钮在独立详情窗口中无效。
  - 根因：详情页内直接使用 `@Environment(\.dismiss)`，在 `NavigationSplitView` 嵌套上下文中不会稳定关闭窗口场景。
  - 方案：由 `SkillDetailWindowRootView` 注入窗口级关闭动作；`SkillDetailView` 增加可注入 `onClose`，优先执行外部关闭动作，未注入时回退 `dismiss()`。
  - 回归：新增 `nolonTests/SkillDetailViewCloseActionTests`，覆盖“自定义关闭优先”和“无自定义时回退 dismiss”两种路径，测试通过。

  - 方案：三类卡片统一增加“Copy Title”菜单项，并在卡片视图显式 `textSelection(.disabled)`，避免正文被选中复制。
  - 复用：新增 `ResourceCardCopySupport` 统一处理标题清洗与复制行为。
  - 回归：新增 `nolonTests/ResourceCardCopySupportTests`，覆盖标题裁剪、空标题忽略、复制内容正确性，测试通过。
