## Codex Sessions Row 点击即展开，移除独立展开按钮
- 决策：会话 row 右侧不再保留单独的展开按钮，只保留菜单；点击整条 row 直接展开/收起详情。
- 原因：菜单和展开按钮并排时控制区显得零碎，用户已经明确接受“点击条目即展开”的交互，不需要再维持第二个显式展开入口。
- 实现：`UnifiedCodexSessionViews` 中 compact row 的 `onTapGesture` 改为 `onToggleRowExpansion`；原右侧 `chevron` 按钮和对应文案被删除。

## Codex Sessions 单会话 Row 状态并入标题行
- 决策：单会话 row 不再用独立 `Live / Archived / Read Only` pill 承载状态，而是把状态直接并入标题行，减少首行高度和视觉割裂。

- 测试：`CodexSessionsCardSnapshotTests` 新增 `single session row merges status into title and keeps subtitle compact`；定向测试通过，结果 `20/20` 全绿。

- 行为变化：`loadSessionTimeline` 现在复用 usage index；对未变化 rollout，详情时间与 usage 都直接命中磁盘缓存，不再重复整文件扫描。若 rollout 缺少可解析时间戳，则继续回退到文件 `mtime`。
- 验证：
  - `swift test --package-path libs/Providers --filter CodexSessionStoreTests` 通过，包含 timeline cache hit 新增场景。
  - `xcodebuild build -project nolon.xcodeproj -scheme nolon-tests -destination 'platform=macOS' -clonedSourcePackagesDirPath /Users/linhey/Library/Developer/Xcode/DerivedData/nolon-daifteoyynegwuevitolzuidfhnx/SourcePackages -derivedDataPath /tmp/nolon-codexsessions-memory-build` 通过。
