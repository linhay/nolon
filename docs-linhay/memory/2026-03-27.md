## 16:30 NolonUI 卡片视图复用收敛（Remote + ProviderCards）
- 目标：减少相似视图实现，统一右上角菜单样式与上下文菜单按钮，降低后续维护成本。
- 决策：在 `NolonUI` 内新增共享视图组，不在主工程侧做桥接样式。
- 新增复用：
  - `Shared/EllipsisMenuButton.swift`：统一 `ellipsis` 菜单按钮样式。
  - `Shared/ContextMenuCommonButtons.swift`：统一 `View Details / Show in Finder / Install / Delete` 菜单项。
  - `Remote/ResourceCardReusableGroups.swift`：统一资源卡片 header/summary/context menu 组装。
  - `ProviderCards/ProviderCardReusableGroups.swift`：统一 reveal+delete 菜单组；新增 `ProviderCardTitleMenuRow` 统一标题+菜单头部行。
- 调整范围：
  - Remote：`ResourceSkillCardView`、`ResourceWorkflowCardView`、`ResourceMcpCardView`、`ResourceCardScaffold`。
  - ProviderCards：`WorkflowCardView`、`RuleCardView`、`AgentDocCardView`、`SkillCardView`、`McpServerCardView`、`ProviderSkillCardView`。
- 结果指标：
  - 重复菜单文案命中（`View Details/action.show_in_finder/action.install/action.delete`）从 `25 -> 12`。
  - ellipsis 菜单样式重复命中降到 `0`。
- 验证：
  - `xcodebuild build-for-testing -project nolon.xcodeproj -scheme nolon-tests -destination 'platform=macOS'`：`0 error`。
  - `xcodebuild test -project nolon.xcodeproj -scheme nolon-tests -destination 'platform=macOS'`：`** TEST SUCCEEDED **`。
