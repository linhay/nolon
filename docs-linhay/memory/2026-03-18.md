## 16:45 Resource Center Git 仓库作用域修复
- 现象：选择 `github.com` 下 Git 仓库（如 `linhay@harmony-next.skills`）时，`Skills` 列表混入全量本地已安装技能，仅当前仓库结果被置顶。

- 决策：将“installed 补齐”限制在 `clawdhub` 场景；Git/local/global 不再注入 `installedOnly`。
- 代码：
