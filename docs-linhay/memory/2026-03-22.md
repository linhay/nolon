## 资源中心 Git 仓库「在 Finder 中显示」回归修复（2026-03-22 23:13 +0800）
- 现象：资源中心仓库侧栏中，Git 仓库点击 `Reveal in Finder` 无响应（路径不存在时静默失败）。
- 根因：`RemoteRepositorySidebarViewModel.revealInFinder` 直接使用 `effectiveSkillsPaths`，当路径已迁移/未同步/老配置为绝对路径时，传入 Finder 的目标不可达。
- 修复：
  - 新增 `revealTargets(for:baseClonePath:fileManager:)`，统一解析可展示目标路径。
  - Git 仓库兼容三类路径：`.`、相对路径、历史绝对路径（legacy）。
  - 路径不存在时回退到最近存在的父目录，保证 Finder 至少能打开仓库根或其上级有效目录。
  - `revealInFinder` 改为只消费 `revealTargets` 的结果，并在空结果时打 warning 日志。
- 测试（先红后绿）：
  - 新增 `RemoteRepositorySidebarViewModelTests` 3 个场景：
    - 相对 skills 路径解析到 clone 子目录
    - 绝对 skills 路径按原值处理
    - 配置路径缺失时回退到 clone 根目录
  - `xcodebuild -project nolon.xcodeproj -scheme nolon-app -destination 'platform=macOS' -only-testing:nolonTests/RemoteRepositorySidebarViewModelTests test` 通过
  - `xcodebuild -project nolon.xcodeproj -scheme nolon-app -destination 'platform=macOS' -only-testing:nolonTests/ProviderContentTabViewVisibilityTests test` 通过
