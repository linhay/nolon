## 16:53 Codex session 窗口 0% 立即刷新策略修复
- 背景：DS 账号卡片出现 `session now 0%` 时，用户预期应立即刷新以拉取重置后的额度状态。
- 变更：在 `ProviderUsageEngine.codexScheduledRefreshDecision` 增加短窗口 reset 触发的一次性立即刷新决策：
  - 条件：最短窗口 `remainingPercent <= 0` 且 `resetsAt <= now`。
  - 行为：若该窗口重置后尚未刷新，则返回 `shouldRefresh = true`（即时触发）；若已在该重置点后刷新过，则返回 `already_refreshed`，避免连续抖动。
  - 保护：仅当存在“更长窗口且仍为 0%”时才抑制该立即刷新；单窗口账号不会被抑制。
- 测试：`ProviderUsageEngineManualRefreshTests` 新增
  - `GivenShortestWindowResetReachedAtZero...ThenTriggersOneImmediateRefresh`
  - `GivenSingleWindowResetReachedAtZero...ThenStillTriggersImmediateRefresh`
