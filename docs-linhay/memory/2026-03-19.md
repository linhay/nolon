## 2026-03-19 SKProcessRunner PTY 崩溃修复（SIGABRT）

- 现象：nolon 在 `SKProcessPTYSession.init` 的后台读事件中调用 `NSFileHandle.availableData` 触发 Objective-C 异常，进程 `abort`（崩溃栈定位到 `SKProcessPTYSession.swift`）。
- 根因判断：文件句柄在并发退出/关闭窗口下可能进入无效状态，`availableData` 抛 `NSException`，Swift 层不可捕获。
- 修复：
  1. 将 `SKProcessPTYSession` 读路径从 `FileHandle.availableData` 改为 `read(fd, ...)`。
  2. 将 `SKProcessPipeSession` 同步改为 `read(fd, ...)`，避免同类崩溃点。
  3. Providers 依赖改为仓库内 `references/SKProcessRunner`，确保修复可追踪。
- 测试：新增 `testPTYSessionRapidTerminateDoesNotCrash`，并通过；`CodexStatusProbeTests`、`TTYCommandRunnerTests` 通过；网关 stop/start/status 回归通过。
